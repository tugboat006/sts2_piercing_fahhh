# Piercing Wail Sound

A mod for Slay the Spire 2 that plays a custom "FAHHH" sound effect when Piercing Wail is played in combat.

## Requirements
- [BaseLib](https://github.com/Alchyr/BaseLib-StS2/releases)

## Installation
1. Install BaseLib into your STS2 mods folder
2. Copy the `PiercingWailSound` folder into:
   `Slay the Spire 2/mods/`
3. Launch the game with **Load with Mods**
